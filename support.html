BoatRun — Support

Last updated: 19 July 2026

BoatRun is a set of rowing performance tools: Metrics, Analyser, Coach and Viewer. If something isn't working, or you have a question, this page will help.

Getting started

  • Full setup and usage instructions are in the in-app Guide, accessible from the About tab of any app.
  • Metrics must be installed to the home screen (Add to Home Screen on iOS, Install app on Android) to record sessions reliably in the background.
  • On iPhone, Metrics needs Precise Location enabled: Settings → Privacy & Security → Location Services → Safari Websites → Allow Location Access While Using the App → Precise Location.

Common issues

  • Recording won't start — make sure the 8-second calibration has finished; the Start button stays disabled until it completes.
  • Missing session after recording — check the app's storage settings; sessions are saved locally first, then optionally backed up to your own Google Drive if you've signed in.
  • Strava upload not showing up — check that Strava is still connected in Settings; you may need to reconnect if the connection has expired.
  • Live squad view not updating — confirm the rower and coach are using the same session code, and that both have a working internet connection.
