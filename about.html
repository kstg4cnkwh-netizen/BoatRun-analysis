About BoatRun

Rowing performance tracking — on-water capture, post-session review, squad coaching.

1. Metrics — the rower's app

Installed on the phone mounted in the boat. Records stroke rate, pace, catch quality, and run loss live from motion + GPS.

Open Metrics

On iPhone: Allow precise location: Settings → Privacy & Security → Location Services → Safari Websites →Allow Location Access While Using the App. Select Precise Location

On the phone: open the link above, then Share → Add to Home Screen (iOS) or menu → Install app (Android).

2. Coach — the squad dashboard

Installed on the coach's phone or tablet. Shows live stroke data per rower while the squad is on the water. Upload workouts and control workout laps.

Open Coach

Same install step as Metrics.

3. Viewer — live view of squad position, pace and stroke rate

No install needed - just bookmark it. Get a connection code from the coaches and join.

Open Viewer

4. Analyser — this site

No install needed — just bookmark it. Use it on a desktop (best) or iPad after a session to review detailed stroke analysis and compare sessions.
