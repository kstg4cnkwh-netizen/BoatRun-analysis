Select an item, or add a new one.
Lane: one-way, drawn in the direction boats travel (yellow, with arrows). Divider: pass either side (dashed red). Hazard: one click for a point (post, buoy), more for a line (sandbank, wall).
Click the map to add points to the selected item. Drag a point to move it, double-click a point to delete it. Open a course file to add lines to it: its sectors are kept and shown in grey. Download saves the same file with the lines added.
